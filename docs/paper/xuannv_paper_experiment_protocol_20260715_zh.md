# 玄女月度地理嵌入论文实验协议

## 1. 论文定位

论文定位为城市尺度月度多模态嵌入框架，不将玄女表述为全球基础模型。核心问题是：冻结64维月度嵌入后，能否通过少量标注和轻量下游头完成多类城市地物制图。

主标题暂定：

> XuannvEarth: A City-Scale Monthly Multimodal Embedding Framework for Label-Efficient Urban Mapping

## 2. 统一评测规则

- 主评测使用连续空间block 5-fold，而不是随机patch划分。
- 每折使用一个连续地理带测试、相邻地理带验证，并从训练集剔除一格空间缓冲区。
- 所有玄女、AEF、DINOv3和Raw基线共用相同split、shot、head、seed与训练预算。
- 阈值只在验证集选择；正文报告测试集`F1@validation threshold`、AP、AUC-ROC和IoU。
- 测试集oracle最佳F1只作为附加上限，不作为论文主指标。
- 主表报告5-fold × 3-seed均值、标准差和空间patch配对置信区间。

固定split：`configs/eval/haidian_spatial_5fold_buffer1_seed42.json`。

## 3. 实验矩阵

| 编号 | 实验 | 目的 | 当前决策 |
|---|---|---|---|
| E0 | P10C生产版统一空间评测 | 建立论文基线 | 必做 |
| E1 | 40/80/150严格嵌套数据规模 | 判断数据规模影响 | 旧实验降为探索；重新训练；160仅保留为fold 0 pilot |
| E2 | 无OSM、仅粗OSM土地利用、probe无hard-negative、完整配方 | 分离粗弱语义、细粒度probe与困难背景作用 | 旧实验初始化受污染；重新训练 |
| E2-HR | 去高分细节注入 | 验证高分数据对边界的作用 | 必做 |
| E2-Mask | 去结构化输入破坏 | 验证困难重建作用 | 必做 |
| E3 | 5-fold × 3-seed轻量probe | 统计稳定性 | 已完成随机fold版；空间版重跑 |
| E4 | 独立人工标签 | 排除OSM同源泄露 | 必做；ESRI结果只作训练目标可读性诊断 |
| E5 | 哈尔滨从零训练 | 验证配方可复现 | 当前训练继续完成；不称零样本泛化 |
| E5-ZS | 海淀模型直接测试哈尔滨 | 跨城市迁移 | 建议补充 |
| E6 | Raw/AEF/DINOv3统一基线 | 公平横向比较 | fold0版仅探索；空间版重跑 |
| E7 | 1/3/6个月、时间池化、月份打乱 | 证明月度建模价值 | 若正文主张月度优势则必做 |
| E8 | 晴空率/缺模态分层评测 | 验证云雾和缺测鲁棒性 | 低成本必做 |

## 4. 训练数据划分

空间fold 0包含64个测试patch、64个验证patch和20个缓冲patch，剩余172个候选训练patch。五折候选训练池分别为172、157、150、176和151，因此完整空间5-fold scaling必须使用每折严格嵌套的40/80/150个patch；测试patch不参与embedding训练、验证或checkpoint选择。现有160-patch训练仅作为fold 0 pilot，不进入完整5折scaling主结论。

生产版P10C使用海淀全域训练，因此其原有结果属于城市内传导式制图。论文将同时报告该业务设置和空间独立设置，禁止混为一种泛化结论。

## 5. 当前实验处理

- E5哈尔滨训练继续到800 epoch。它已经消耗约350 epoch，且可用于验证配方在第二城市能否重现。
- 旧E1权重保留，但不再导出或执行论文主评测，因为其训练子集不严格嵌套且与验证集重叠。
- 旧E2权重保留为开发记录，但不进入因果消融表，因为初始化已接受OSM语义监督。
- E3随机fold统计、E4 ESRI结果、E6 fold0结果保留为诊断和补充材料，不作为论文最强泛化证据。

## 6. 启动顺序

1. E5完成后先导出哈尔滨embedding并执行统一空间评测。
2. 两卡一组并行训练E1/E2第一批：fold 0完整160 pilot、完全无OSM、仅粗OSM土地利用；后续完整5折主实验统一使用150上限。
3. 第二批训练：probe无hard-negative、去高分、去结构化mask。
4. 第三批并行训练完整40与完整80。
5. 每个checkpoint导出后立即执行同split的轻量probe，汇总后删除中间embedding，只保留最终结果与必要可视化。
6. 并行完成人工独立标签和E7推理侧时序消融。
