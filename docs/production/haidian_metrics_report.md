# 海淀区生产版指标报告

版本：`haidian-embedding-v1`

候选模型：P10C `epoch_800.pt`

验证方式：202604 月海淀区 embedding，固定 fold-0，简单 MLP 下游头，任务为建筑、道路、水体。

| 任务 | AP | F1_best |
|---|---:|---:|
| 建筑提取 | 0.4392 | 0.4832 |
| 道路提取 | 0.5726 | 0.5232 |
| 水体提取 | 0.6092 | 0.6306 |
| 平均 | - | 0.5457 |

说明：

- 这里是快速生产验收指标，不等同于完整 5-fold 报告。
- 下游头为简单 MLP，用于验证 embedding 的线性/浅层可读性。
- 320 patch 全域可视化已上传至 ModelScope dataset。
