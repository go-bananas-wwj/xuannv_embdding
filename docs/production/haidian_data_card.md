# 海淀区生产版数据卡

版本：`haidian-embedding-v1`

区域：北京市海淀区 320 个 128×128 patch。

时间范围：2025-12 至 2026-05，共 6 个月。

输入源：

- Sentinel-2
- Sentinel-1
- Landsat
- 高分辨率光学影像
- 高分辨率 SAR
- OSM 弱语义标签

训练目标：

- 多源重建：S2、S1、Landsat、高分光学、高分 SAR。
- OSM 弱语义约束：建筑、道路、水体、绿地、农业、居住、商业、工业、施工地等弱标签。
- 困难重建：随机遮挡模态、月份和空间块，让 embedding 更稳健。

重要边界：

- OSM 标签是弱标签，存在漏标和时效误差。
- 本版本只承诺海淀区专用效果，不声明跨城市泛化。
- 权重、embedding、下游头不进入 Git，统一存放在 ModelScope dataset。
