成果摘要

一份 embedding，多类任务复用。 主模型只生成一次海淀月度 embedding；下游使用冻结特征加轻量 conv3×3 头，即可完成建筑、道路、水体、施工工地及多个 OSM 细粒度类别的制图。
最突出的应用价值是少标注快速制图。 在 5-shot 与 10-shot 条件下，玄女 embedding 在建筑、道路和水体上均优于直接使用原始多源影像训练的强下游基线；新类别可用少量样例快速建立初图。
版本口径。 6 月的 P2A/P1B 为历史实验，P10A 是 P10 训练链中的早期候选；当前稳定生产模型是 P10C epoch 800。后续单项更高的版本不以牺牲通用多任务能力为代价替换生产底座。

模型、数据与训练方法

月度多源观测Sentinel-2、Sentinel-1、Landsat；稀疏高分光学与高分 SAR。
数据质检云雾、阴影、无效像素、配准与多景质量筛选。
自监督表征多模态重建、月份/模态/空间块遮挡与跨月时空融合。
弱语义增强清洗后的 OSM 广义地物语义探针与困难负样本。
下游制图冻结月度 embedding，少量标注训练轻量头并输出全域图。

输入与质量控制

  • 主时序：Sentinel-2（12 通道）、Sentinel-1（VV/VH）和 Landsat（7 通道）。
  • 高分光学、高分 SAR 作为独立模态，重采样至统一 10 m 网格。
  • 云雾和无效区域由有效像素 mask 排除出重建目标；同月多景只使用质量较好的观测。
  • 训练前随机抽检每月各源影像、mask、OSM 栅格和空间对齐，避免把云雾与错位当作地物语义学习。

P10C 的关键训练设计

  • 保持 128×128 空间输出，避免把边界细节压缩到低分辨率格网。
  • 重建权重强调高分光学细节，降低噪声较大的 S1/SAR 影响。
  • 随机遮挡月份、模态和空间块，要求模型利用其他有效观测恢复目标，而非记忆单一输入。
  • 13 类 OSM 弱语义以辅助 probe 接入，配合困难负样本，改善相似地物的可分性；不直接使用最终人工下游标签训练主模型。

零训练向量检索：从一个样例寻找全域相似地物

该实验不训练任何下游分割头。先只在训练集的少量目标像素上求 64 维平均向量，形成类别原型；随后对测试区域每个像素与原型计算 cosine similarity，验证集选择阈值后输出测试结果。它直接回答：不训练任务头时，语义相近地物是否已经聚集在 embedding 空间中。

提供一个查询样例从已知建筑、道路或水体中圈选少量正像素。
构造类别原型对 query embedding 求平均；水体可同时引入负样本原型。
全域余弦相似度逐像素计算与类别原型的 cosine similarity，生成连续热力图。
验证集选阈值只在验证集选最佳阈值，避免用测试信息调参。
候选发现与制图输出全域候选、排序和单 patch 对照，供人工快速核查。

PU + Query：1--9 个用户圈选 Polygon 的即时制图

参考 embedding-api 的 PU + Query 复现提交，新补充实验模拟业务人员只圈选极少量目标区域时的即时制图。这不是训练下游网络：每个 Polygon 等权形成前景原型；模型从正样本周围排除边界后，只取最不相似的 30% 未标注像素作为可靠背景；再以 F0.5 选取强调 Precision 的阈值。当前 patch 的极高置信像素可触发一次受面积保护的 Query 自适应。

用户圈选 1--9 个 PolygonPolygon 内为确定正样本，外部仅是未标注区域。
PU 前景/可靠背景原型不把全部未标注像素误当负例，降低少标注时的大面积误检。
受保护 Query 自适应只使用当前 patch 的极高置信响应；面积异常增长时自动回退。
即时候选制图不训练网络，输出概率候选图；达到 10 个 Polygon 后切换 Conv3×3 训练路径。

已具备较好可用性的类别

林地、湖泊、耕地、河流、操场、建筑物、主干道、施工工地与水体大类，可按统一流程接轻量下游头，形成区域级制图结果。

建议作为检索或人工核查辅助的类别

池塘、裸地、草地、火车站受目标尺度或 OSM 标签噪声影响较大；停车场、体育场、湿地、垃圾场、机场样本不足，应补充人工标注后再作为正式检测任务。

从“标一个点”到“找一类目标”

对一个已标注的操场、公园或其他目标区域，提取其 embedding 向量并在全域计算相似度，即可得到同类候选区域。该流程适合稀有类别的样本发现、人工核查和半自动标注，不替代最终语义分割验证。

交付物与业务使用流程

获取月度 embedding选择月份与区域，读取 P10C 生成的 64 维特征场。

推荐的任务头选择

  • 快速小样本二值制图：优先 conv3×3，兼顾轻量、稳定与局部空间连续性。
  • 只需验证向量可分性：使用 linear 或 MLP probe，但需检查概率校准，不能只看 AUC。
  • 标签充分且追求单任务最高上限：可使用原始多源影像 + UNet/DeepLab-lite；其代价是任务间无法直接复用主模型。

适用边界与下一步改进

当前适用边界

  • 海淀 P10C 是区域传导式生产模型，适合海淀区域的月度制图与下游快速迭代。
  • OSM 是弱语义标签，地图未标注区域不等于真实负类；关键业务类别仍应补充独立人工验证。
  • 充分标注条件下，原始影像 + 强分割模型可获得更高单任务上限。
  • 云雾、缺失数据源、配准偏差和 10 m 以下小目标仍是主要误差来源。

面向业务的后续提升方向

  • 补充建筑与施工工地独立人工验证集，量化真实业务误差。
  • 为停车场、湿地、垃圾场、机场等稀有类建立标注规范与样本池。
  • 在持续月度数据中验证同一任务头跨月迁移，并将异常区域送入人工复核闭环。
  • 以全国多区域数据扩展预训练底座，提高跨城市和复杂成像条件下的稳健性。
