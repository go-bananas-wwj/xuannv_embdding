一句话科学主张

拟验证的主张：将连续六个月的多源遥感观测编码为按月份索引的 10 m、64 维稠密特征场后，冻结该表示并只训练一个浅层下游头，能否在严格空间留出区域中支持多种城市制图任务，并降低所需的标注 patch 预算。
当前不作的主张：不宣称玄女全面超过 AEF/DINO、不宣称月度输出天然提高变化检测、不将生产版 P10C 当作空间泛化证据，也不把 OSM 标签评测直接当成完全独立的泛化证明。

论文大纲

  1. Introduction：城市制图需要反复训练任务模型；提出“按月份索引、可复用、标注 patch 效率”的问题。
  2. Related Work：AEF/EO embedding、多模态遥感、掩码重建与 OSM 弱监督的现状与边界。
  3. Materials and Methods：首先呈现 Experimental and Technical Design，再说明区域、数据质量、OSM、模型、损失和冻结表示评测。
  4. Results：空间 5-fold 主结果、few-shot 曲线、基线对比、数据规模和消融、云雾/缺模态/时间/跨城分析。
  5. Discussion：解释弱标签、区域数据规模、有效维度、月度云雾与多源对齐带来的限制。
  6. Conclusion and Availability：总结可复用月度嵌入的适用范围，公开代码、配置、划分与可发布产物。

主文控制在约 8,000–10,000 词、摘要不超过 250 词、主图表合计不超过 10 个；未完成实验一律标记为 pending，不进入摘要或结论。

已有结果能说明什么

可作为生产版证据

  • P10C 在海淀多任务、few-shot、检索和全域制图上已有完整业务验证。
  • 同一轻量头下，P10C 与 AEF 64 维对比总体同量级；施工、道路有竞争力，水体存在差距。
  • 少量标注下，玄女对 raw 多源影像强基线在建筑、道路、水体上有优势，尤其是 5-shot 和 10-shot。
  • 有效秩与下游效果不呈简单正相关：P14/V4 的诊断为论文 Discussion 提供了有价值的负结果。

尚不能进入论文主结论

  • 完整配方对 no-OSM、no-masking、no-hard-negative 的稳健差异。
  • 数据量 40/80/150 patch 的跨折 scaling 曲线。
  • 独立标签上的 OSM 弱监督收益和类别留出能力。
  • 月度时间上下文、云雾/缺模态鲁棒性、哈尔滨统一评测与跨城迁移。
论文写作原则：当前生产版数字可放在应用案例或预实验；摘要、主结果与结论只使用通过门禁、登记在正式结果注册表中的空间独立结果。

为什么这套方案更经得起审稿

1. 训练与测试隔离
测试区、验证区和空间缓冲区均不参与 encoder 训练；避免相邻 patch 信息泄露。
2. 基线同协议
玄女、AEF、DINOv3、raw baseline 使用同一标签、同一空间划分、同一 head、同一训练预算和验证集阈值。
3. 统计而非单点最优
主结果报告 5-fold × 3 下游 seed 的均值、标准差与空间配对置信区间，而非只选最好的一个 fold。
4. 可追溯与失败公开
每个结果绑定 Git commit、配置、权重、数据/标签清单、阈值、预测和汇总代码；失败与负结果同样保留。
