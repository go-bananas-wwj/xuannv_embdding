# 图5来源与使用边界

`haidian_fewshot_model_comparison.png` 是 2026-07-29 由项目负责人提供的既有
可视化截图，用于申报书“现有技术基础”中的工程流程说明。

图中为三个单 Patch 示例：建筑 `patch_000205`、道路 `patch_000264`、水体
`patch_000106`。每行展示当时的光学影像、P10C 64维嵌入投影、基于 OSM 弱语义
流程选取的支持 Polygon 以及四列历史下游输出。图中标明的 F1/IoU 是对应单 Patch
的局部值，不能用于总体精度、模型优劣、5/10/50-shot 标准评测或跨区域泛化结论。

图中输出的读取器与时相并不完全一致：自研原型为 P10C 月度嵌入的历史输出；AEF
为年度嵌入 Pixel MLP；另有 Sentinel-2 随机森林和 DINOv3-SAT493M 特征的历史
输出。除 AEF Pixel MLP 和 Sentinel-2 随机森林外，其余历史输出的读取器设置在
该截图中未完整保留，因此不将其称为严格的“特征—读取器组合”或横向基准。该图
仅作为“多类特征均可接入下游制图流程”的定性实例。

支持多边形与评价掩膜均来自 OSM 弱语义相关流程，不是独立人工真值，也不是 GEP
指标的独立真值。本图不支持生态系统分类、生态服务实物量或价值量、GEP 核算
准确性的结论。
