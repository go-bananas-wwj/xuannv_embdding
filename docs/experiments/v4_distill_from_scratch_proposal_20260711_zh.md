# V4 方案：从零训练 + 大模型知识蒸馏（颠覆性升级提案）

日期：2026-07-11 分支：v3-semantic-64d（实施后切 v4-distill）

## 1. 为什么之前的提升都是 0.0x —— 瓶颈诊断

P11→P14 四轮实验，每轮下游变化都在 ±0.005 级别。归根结底不是损失函数不够好，而是：

**我们只有 744 个 patch（海淀 320 + 哈尔滨 424，约 1200 km²），从零训练的模型
早已"背下"全部数据。调整损失只是在同一块有限信息里重新分配容量，
天花板锁死在数据量上。**

对照行业实践：
- **AEF**（我们的对标）：全球数十亿样本训练，其 embedding 才有跨任务泛化力；
- **DINOv3**（Meta 2025.08，arXiv:2508.10104）：17 亿张图自蒸馏 + Gram anchoring，
  其 **SAT-493M 卫星版**在 4.93 亿张卫星影像上预训练，dense feature 在遥感
  分割/检测上大幅超过既有专用模型；
- **Galileo**（2025.02，arXiv:2502.09356）：多模态全局+局部双对比目标，
  但同样依赖大规模预训练语料。

**我们不可能自己收集 1 亿张影像，但可以把大模型的知识"蒸"进来。**
这就是唯一能带来数量级提升的杠杆：用 DINOv3-SAT493M（ViT-L/16，на 4.93 亿
卫星图预训练）作为教师，把它对海淀/哈尔滨每个像素的语义理解蒸馏进我们的
64 维时序模型。

## 2. V4 设计：三支柱

### 支柱一：DINOv3-SAT493M 特征蒸馏（核心，预期最大收益）

- 教师：`facebook/dinov3-vitl16-pretrain-sat493m`（1024 维 patch token，16×16 patch）。
- 输入教师的是**高分光学影像**（0.5m Google/2m 高分），教师输出 dense feature map，
  双线性上采到 128×128 后作为逐像素蒸馏目标。
- 学生（我们的模型，**从零初始化**）输出 64 维 embedding_map，经一个可丢弃的
  1×1 conv 投影头映到 1024 维，与教师特征做 cosine 蒸馏损失 + **Gram anchoring**
  （DINOv3 关键技巧：对齐 patch 间相似度矩阵而非绝对特征，保持 dense feature
  的空间结构，防长训退化）。
- 教师特征**离线预计算一次**（744 patch × 高分月份，NPU 推理约 1-2 小时），
  训练时零额外开销。
- 关键洞察：教师看不到时序/SAR/多光谱，学生看得到。蒸馏提供"这个像素是什么"
  的静态语义底座，我们原有的重建+对比目标继续学习"它如何随时间变化"。
  两者互补而非替代。

### 支柱二：双区域全数据从零训练

- 744 patches（海淀+哈尔滨）联合训练，数据量 2.3 倍于 P13/P14 的海淀-only；
  哈尔滨的气候/城市形态差异本身就是正则化。
- 从零初始化（用户要求），彻底摆脱 P10C/P13 血统问题。

### 支柱三：保留 v3 已验证有效的组件

- 语义原型对比（P14 证明对检索/类中心分离有效：P13→P14A 检索三任务全升）；
- uniformity + covariance + 有效秩监控（P14A 有效秩 12.03 达标）；
- vMF bottleneck 64 维单位球面、128×128 输出、多源时序输入——产品形态不变。
- construction 任务权重 2×保护（P14 教训）。

## 3. 损失配方（草案）

| 损失 | 权重 | 说明 |
| --- | --- | --- |
| 多源重建（既有） | 1.0 | 时序信息主干 |
| **DINOv3 蒸馏 cosine** | **0.5，warmup 0** | 从第一步就注入教师知识 |
| **Gram anchoring** | **0.2** | patch 相似度结构对齐 |
| 语义原型对比 | 0.12（constr 2×） | v3 已验证 |
| uniformity / covariance | 0.16 / 0.08 | v3 已验证 |
| 边界对比 | 0.08 | v3 已验证 |

## 4. 预期收益依据

- DINOv3 论文：SAT-493M dense feature 线性 probe 在 loveDA/iSAID 等遥感分割基准
  上超过专用 SOTA 5-15 个点——不是 0.0x 而是 0.05~0.15 量级；
- 我们的 few-shot 短板（strong head 需要细粒度纹理）正是 DINOv3 dense feature
  的强项（其 Gram anchoring 就是为 dense 质量设计）；
- AEF 论文自己也用了 teacher 蒸馏（其 v1 模型蒸给 v2）。

## 5. 实施步骤

1. 下载教师权重，NPU 推理验证（进行中）；
2. 离线预计算 744 patch 教师特征（存 /data/xuannv_embedding/teacher_features/）；
3. 实现 `DistillLoss`（cosine + Gram anchoring）接入 TotalLoss；
4. V4 配置：双区域 manifest、从零初始化、6 卡 800 epochs；
5. sanity → 全量训练 → 与 P10C 全协议对比（conv3x3、few-shot、检索、诊断）。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 教师是纯光学，SAR/时序信息可能被挤压 | 蒸馏只作用于 embedding 的投影头分支，重建损失保持主导（1.0）|
| 高分影像与 S2 配准误差 | Gram anchoring 对绝对位置误差更鲁棒；蒸馏目标降到 64×64 再上采可平滑误差 |
| NPU 上 ViT-L 推理兼容性 | 只离线推理一次，失败可退 CPU（744 patch 可接受）|
| 64 维学 1024 维教师容量不足 | 投影头承担维度差；Gram 目标本质是相似度结构，与维度无关 |
