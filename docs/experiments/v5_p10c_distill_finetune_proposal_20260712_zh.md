# V5 方案：P10C 基座 + DINOv3 蒸馏微调（海淀单区域，待审阅）

日期：2026-07-12　状态：**待用户审阅，未启动训练**

## 0. 一句话方案

**不再从零、不再动哈尔滨**：拿生产版 P10C epoch_800 当基座，只用海淀 320 patch，
以"低强度、带衰减、只在前中期"的 DINOv3-SAT493M dense 蒸馏做 400 epoch 微调，
把 V4A 验证过的 construction 能力"移植"进 P10C，而不动摇它已有的判别结构。

## 1. 第一性原理分析：为什么这么做

### 1.1 收益的唯一已验证来源

全部历史实验中，**唯一带来 >0.05 量级下游提升的动作是 DINOv3 蒸馏**
（V4A construction AP +0.067）。P11-P14 所有自监督正则微调都在 ±0.01 打转。
第一性原理：320 patch 自学的信息量上限锁死，**新信息只能从外部大模型注入**。
所以 V5 必须保留蒸馏，这是不可谈判项。

### 1.2 损失的唯一已确认来源

V4A 输掉的所有指标（few-shot、检索、building/water）都指向同一个变量：
**类中心判别结构被破坏**（between/within 0.736→0.379）。破坏来自三个叠加因素：
从零初始化（丢掉 P10C 血统数千 epoch 的判别积累）、双区域稀释（哈尔滨占 57%）、
高强度通用蒸馏(0.5)+高 uniformity(0.16)。
V5 把三个因素全部消除：**基座=P10C（判别结构天生就在）、只用海淀、
蒸馏强度降到 0.15 且 200ep 后衰减到 0、uniformity 保持 P10C 原值 0.06**。

### 1.3 为什么"基座+蒸馏微调"大概率有效——不对称性论证

关键不对称：**判别结构难建易毁，语义知识易注难保**。
- V4A 证明：从零+蒸馏能建立语义（construction 赢）但重建判别结构失败（其余全输）；
- P10C 证明：判别结构已经存在且稳固（数千 epoch 累积）；
- 微调的本质是小步扰动：lr 2e-6 + 低权重蒸馏下，参数漂移有界，
  P10C 的判别结构最坏情况下轻微退化（可用 epoch 选择回退），
  而 construction 方向的语义梯度是净增量。
**下行风险有界（有 P10C 兜底、逐 checkpoint 评测可早停），上行空间已被 V4A 实证。**
这是所有候选路径中唯一"损失有下限、收益有实证"的组合。

### 1.4 为什么不是 V4B

V4B 仍是"从零+双区域"，赌的是损失权重调度能在 800 epoch 内同时完成
"注入语义+重建判别"两件事。V4A 已证明重建判别结构是难题，
且它拿不到 P10C 血统的训练预算复利。用户判断其不达标，我同意：
它的 few-shot 上限大概率仍低于 P10C。已停训（epoch 39）。

## 2. 行业最佳实践对照

1. **持续预训练不如蒸馏微调破坏性小**（LoRA/adapter 社区共识；我们等效做全参数
   但超低 lr 微调，微调总更新量与 adapter 同量级）；
2. **特征蒸馏权重衰减/早停是标准做法**（FitNets→BEiT-distill 系列：教师信号
   只在早中期有益，后期反而抑制任务特化）；V4A 的教训与此完全一致；
3. **单域生产模型用域内特化而非跨域泛化**（遥感届 SatMAE/Scale-MAE 微调协议
   都是"大模型预训练→目标域小数据特化"，从不反向要求小模型学通用性）；
4. **蒸馏目标选 dense/patch 级而非全局**（DINOv3 官方 linear probing 协议、
   AEF 论文均用 dense feature）——我们已实现（cosine+Gram），直接复用。

## 3. 具体配置（相对 P10C 的全部差异，仅 5 处）

| 项 | P10C | V5 | 理由 |
| --- | --- | --- | --- |
| 初始化 | P10A e800 | **P10C e800（生产版）** | 保住判别结构 |
| distill_weight | 无 | **0.15，ep0-200 后余弦衰减→0（ep400 归零）** | 低强度注入，后期完全让位 |
| distill_gram_weight | 无 | **0.06** | 结构对齐辅助，比例同 V4A |
| epochs | 800 | **400** | 微调不需要 800；ep100 起每 100ep 评测 construction+few-shot 快检 |
| 数据 | 海淀 320 | 海淀 320（不变） | 用户指令：不做哈尔滨 |

**其余一切与 P10C 完全相同**：lr 2e-6、uniformity 0.06、semantic_probe 0.14 +
hardneg 0.35、监督采样、单区域 manifest。不加原型对比、不加边界对比
（P14A 已证明它们在错误基座上无效，在 P10C 基座上属于额外变量，本轮不引入——
**一次只改一个变量：蒸馏**）。

教师特征海淀 320 patch 已全部预计算完毕，零额外成本。

## 4. 验收标准（相对 P10C 生产版）

硬性：construction F1/AP ≥ +0.03；building/road/water conv3x3 回退 ≤0.005；
few-shot 18 项胜率 ≥ 50%；检索三任务不低于 P10C-0.01。
若 ep100/200/300/400 中任一 checkpoint 达标即可定版；全部不达标则结论为
"P10C 已是 320 patch 数据量下的效果上界，需要新数据而不是新算法"。

## 5. 预期与风险

- 预期：construction 移植成功概率高（V4A 实证+低破坏微调）；few-shot 大概率持平
  略升（判别结构不动）；最坏情况 = 全部持平，回退成本为零（生产版仍是 P10C）。
- 风险：蒸馏信号太弱（0.15）不足以移植 construction 能力 → 若 ep200 快检
  construction 无起色，中途把 distill_weight 提到 0.25 重启，仍在预算内。
- 训练成本：400 epoch 单区域 320 patch，6 卡约 5-6 小时，远低于 V4A/V4B。

## 6. 更长期的话（用户"小打小闹"关切的正面回应）

同意：在 320 patch 上继续调损失函数已接近收益上界。V5 之后若还要大幅提升，
真正的杠杆只有两个，都不是算法：
1. **扩海淀训练数据**（320→千级 patch：扩时间窗到 12 个月、扩相邻城区做
   预训练再海淀特化）；
2. **升级教师/直接用教师**（如 DINOv3 特征 + 轻量适配头直接做下游，
   把我们的模型定位成"教师特征的 64 维压缩器"）。
这两条可在 V5 结论出来后单独立项评审。
