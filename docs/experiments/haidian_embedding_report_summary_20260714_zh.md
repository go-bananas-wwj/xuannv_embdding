## 1. 生产版模型效果（P10C epoch 800）

模型输出：每个 10m×10m 地块一个 64 维"语义指纹"，128×128 patch，月度更新。
评测协议：冻结 embedding + conv3×3 轻量探针，海淀 320 patch，202604 月度嵌入，fold-0。

> 术语速查：**Embedding**＝把每个地块压缩成 64 个数字的"语义指纹"；**F1**＝"找得全"与"找得准"的综合分（0～1，越高越好）；**AP**＝不同阈值下的平均查准率；**AUC**＝模型把正负样本排对顺序的概率；**few-shot**＝只给 5/10/50 个样例就学会新类别；**探针**＝冻结模型只训轻量小头，考察 embedding 本身的含金量。

## 2. 与业界主流模型同协议实测对比（海淀区）

将 **Google AlphaEarth Foundations（AEF）官方嵌入**与 **Meta DINOv3-SAT493M**（4.93 亿卫星图预训练 ViT-L）接入完全相同的评测管线（同一批 patch、同一套标签、同一探针、同一 fold）。

| 任务（F1 / AP） | P10C 生产版（64 维） | AEF 官方（64 维，年度） | DINOv3（1024 维 ⚠） | V4A 蒸馏版（64 维） |
| --- | --- | --- | --- | --- |
| 施工工地 | 0.5495 / 0.5435 | 0.5453 / 0.5669 | 0.5817 / 0.5219 | **0.5988 / 0.6105** |
| 建筑物 | 0.4842 / 0.4497 | 0.4856 / 0.4219 | **0.4991 / 0.4821** | 0.4651 / 0.4150 |
| 道路 | 0.5218 / 0.5664 | 0.5169 / 0.5642 | **0.6020 / 0.6733** | 0.5183 / 0.5758 |
| 水体 | 0.6237 / 0.6041 | 0.6661 / 0.6869 | **0.6774 / 0.7201** | 0.5962 / 0.5979 |

⚠ DINOv3 为 1024 维（我们的 16 倍存储/计算成本），原生分辨率 32×32 上采样参评，不属同量级产品形态。

**解读**：

- **vs AEF（同 64 维公平对比）**：P10C 在施工 F1 / 道路 / AUC 上占优，建筑打平，水体落后 0.04。我们以 320 patch 达到与 Google 全球模型总体同一水平，且施工检测（时序敏感）更强——AEF 年度嵌入天然缺失月度时序信息。
- **vs DINOv3 原生 1024 维**：其在建筑/道路/水体更强，印证教师价值上限；我们的 V4A 蒸馏版已在施工检测上**超过教师本身**（0.5988 vs 0.5817），说明"教师语义 + 月度时序"结合的潜力。
- **产品形态优势**：64 维 = 1/16 存储与检索成本；月度更新 vs AEF 年度更新。

## 4. 业务方 18 类地物需求落地盘点

用离线 OSM 矢量新构建 8 个标签层（河/湖/塘水体三分、裸地、体育场、火车站、湿地、垃圾场），在 P10C 生产 embedding 上完成全监督 + few-shot + 原型检索三档评测。

| 判定 | 类别 | 关键数字 |
| --- | --- | --- |
| ✅ **立即可用（9 类）** | 林地、湖泊、耕地、河流、操场、建筑物、主干道、施工工地、水体大类 | 林地 F1 0.81；湖泊 0.54；耕地 0.54；河流 0.38（窄河道 10m 下偏难）；操场 0.39 |
| 🟡 **降级使用（4 类）** | 池塘（限 ≥0.5ha 大塘）、裸地、草地、火车站（检索辅助） | 池塘 0.13；裸地 0.20（OSM 标注噪声大）；草地 0.11（OSM 标注极稀疏，换 Dynamic World 标签可改善） |
| 🟠 **需人工标注（5 类）** | 露天停车场、体育场、湿地、大型垃圾场、机场 | OSM 现成样本 <10 个或标签区分度不足；补充少量人工标注后即可纳入监测流程；现阶段可用嵌入检索缩小人工排查范围（火车站检索 P@10=0.5） |

- 十字路口为道路拓扑点目标，由主干道提取结果骨架化后处理得到，不单独训练。
- AUC 普遍 >0.83：embedding 对这些类均有排序能力，F1 低的主因是 OSM 弱标签噪声与 10 m 分辨率下的小目标。

## 5. 工作历程：20+ 轮训练实验迭代

| 阶段 | 内容 |
| --- | --- |
| v1 基础架构 | 多源时序融合（S2/S1/Landsat + 高分光学/SAR）→ 64 维单位球面 embedding，6 卡 Ascend NPU 训练管线 |
| v2 P1–P8 | 训练信号工程：稀疏采样加权、硬负例对比、时序变化感知、掩码重建重平衡、高分融合注入 |
| v2 P9–P10C | **生产版确立**：长程训练 + OSM 弱监督语义探针 + 硬负例加权 → few-shot 与检索全面最优 |
| P11–P14 | 表征质量优化（维度扩展/大上下文/正则全家桶/原型边界对比）：空间健康度提升，但下游 ±0.01 内浮动 |
| V4A | DINOv3 蒸馏（从零）：施工 AP +0.067 历史最大单项突破，但判别结构被稀释，few-shot 1/18，未达生产标准 |
| V5 | P10C 基座 + 低强度蒸馏微调：证明蒸馏收益依赖从零空间重组，无法注入已固化的模型 |
| 头部扫描 | conv3×3 vs UNet vs UPerNet 复杂度实验（见第 7 节） |

| 指标 | P10C（生产） | P13 | P14A | V4A | V5 |
| --- | --- | --- | --- | --- | --- |
| 施工 F1/AP | **0.5495/0.5435** | 0.5429/0.3891 | 0.5292/0.3543 | **0.5988/0.6105**① | 0.4945/0.4475 |
| 建筑 F1 | **0.4842** | 0.4814 | 0.4830 | 0.4651 | 0.4868 |
| 道路 F1 | **0.5218** | 0.5183 | 0.5203 | 0.5183 | 0.5211 |
| 水体 F1 | **0.6237** | 0.6183 | 0.6253 | 0.5962 | 0.6258 |
| few-shot 胜率 vs P10C | 基准 | — | 0/18 | 1/18 | 3/18 |
| 向量检索（b/r/w） | **0.355/0.449/0.586** | — | — | 0.318/0.397/0.555 | 0.360/0.446/0.575 |

① V4A 施工检测全场最高，可作为**施工检测专用模型**与 P10C 双模型服务（零额外成本）。

P10C 胜出的根本原因：训练预算复利（继承数千 epoch 连续训练链）、监督信号与下游任务同源（OSM 语义探针）、单区域深度特化。

## 7. 下游头复杂度实验：更复杂的头不能带来提升

| 任务 F1 | conv3×3（~4K 参数） | UNet 头（~百K） | UPerNet 头（~百K） |
| --- | ---: | ---: | ---: |
| 施工 | **0.5495** | 0.4987 | 0.4641 |
| 建筑 | **0.4842** | 0.4692 | 0.4663 |
| 道路 | **0.5218** | 0.5126 | 0.5097 |
| 水体 | **0.6237** | 0.6218 | 0.6024 |

**结论**：320 patch 标注量下复杂头全面过拟合（平均 -0.03 F1）。从"头部侧"再次印证：瓶颈不在模型容量，而在数据量——embedding 中可被利用的信息，轻量头已全部利用完毕。

## 8. 核心结论与资源建议：数据量是唯一瓶颈

三组独立证据链共同指向同一结论（320 个海淀训练 patch 已被榨干）：

1. **算法侧**：P11–P14 六轮表征优化，下游指标全部 ±0.01 内。
2. **知识注入侧**：DINOv3 大模型蒸馏——从零训会牺牲判别性（V4A），微调注不进语义（V5）。在 320 patch 上，"通用语义"与"判别结构"不可兼得。
3. **下游头侧**：复杂头全面过拟合，轻量头已榨干 embedding 全部信息。

### 下一步建议（按投入产出排序）

1. **双模型服务（零成本，立即可用）**：P10C 服务全任务 + V4A 专供施工检测（F1 0.599 / AP 0.611，比生产版 +9%/+12%）。
2. **扩充海淀数据（根本解）**：时间窗 6→12 个月、纳入相邻城区做预训练再特化；V4A 已证明更大数据量+蒸馏能建立更强语义。同时为 18 类中的 5 个弱类补充人工标注。
3. **教师直用路线（架构升级）**：DINOv3-SAT493M 特征 + 64 维压缩头，把自研模型定位为教师特征的高效压缩器。
