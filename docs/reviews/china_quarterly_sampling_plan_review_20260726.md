# 中国版季度采样方案独立审查记录

审查日期：2026-07-26

审查对象：

1. `docs/plans/china_quarterly_2020_2021_sampling_plan_20260726_zh.md`
2. `configs/national/china_quarterly_2020_2021_sampling_policy_20260726.json`
3. `docs/plans/word/中国版AlphaEarth全国采样方案_2020_2021季度版_20260726.docx`

## 一、审查方式

方案初稿完成后，分别从空间抽样统计、遥感数据与弱语义、工程复现和正式文档
交付角度进行独立审查。审查智能体之间不共享结论。随后对重复出现的问题进行
合并，以实际代码、现有数据清单和参考文档为准进行修订。

## 二、主要问题与处理

| 问题 | 处理结果 |
| --- | --- |
| 配置种子误写为 20260726，与现有 57,405 点的 20260717 不一致 | 已改为 20260717，并增加测试 |
| 首页把 62,000 目标配额写成已经完成 | 已增加完成状态表，全文改为目标配额 |
| 旧注册脚本无法读取季度策略 | 未伪装为已修复；配置和文档明确标记接口不兼容、端到端链路待开发 |
| UTM 分区交界存在越区和重叠候选 | 新方案增加唯一 owner zone、规范化 footprint 和空间相交检查 |
| 边界宏网格使用估计数量，不是准确整数 n | 新方案要求逐点枚举准确 n，旧脚本仅作为参考实现 |
| 2,595 个空间补样会集中填充未入选边界宏网格 | 改为从全国所有未入选 patch 选择，允许基础宏网格增加一个补样 |
| 各补样脚本对“每宏网格一个”的口径不一致 | 冻结为四个补样层合计最多增加一个，并要求重建旧 60,500 清单 |
| 语义四类可能重叠，无法保证新增 1,500 个唯一点 | 增加主类别优先级、次级原因和同类候补池 |
| 海岸使用固定经纬度距离，不能证明真实陆海交界 | 改为局部米制 CRS，并要求 footprint 同时与陆地面和海洋面相交 |
| 质量门槛只有原则，没有数值 | 增加逐源有效像素、观测数、模态数和配准误差阈值 |
| 雪被和云一起当作无效像素 | 已修正；雪作为有效季节地表状态保留 |
| 三个核心源全部必需会排除长期多云和困难区域 | 改为每季度至少一个光学源加一个其他模态，缺失目标用 mask |
| 年度土地覆盖和 Dynamic World 可能注入伪时间信息 | 限制为年度宽类或置信度伪标签，不监督季度变化 |
| OSM 历史时间不明确 | 规定从 full history 重建 2020、2021 年末快照并记录校验值 |
| 训练、验证、测试空间划分不可复现 | 增加 50 km 父块、25.6 km 缓冲和 1 个百分点比例容差 |
| 补样后不能直接称为全国等概率代表样本 | 注册表增加 inclusion probability 和 design weight |
| 全国比例的统计分母不一致 | 正文同时披露 1.06%面积估算和 1.08%清单估算，最终枚举后重算 |
| 自制全国图可能被误用于对外材料 | 图内和图注明确标记内部技术预览、禁止对外发布 |
| DOCX 使用 Letter、无目录、表格跨页风险 | 改为 A4，增加目录域、页眉页码、重复表头和禁止跨页拆行 |

## 三、保留的实施阻断项

以下内容不属于“写方案”即可自动完成，已在正式方案首页和当前状态章节明确列出：

1. 旧 57,405 点须重新执行 UTM 唯一归属、准确边界枚举和跨区重叠检查。
2. 历史 60,500 点临时清单不能直接作为正式注册表。
3. 四池语义补样、季度合成、影像数据修复队列和空间 split 仍需开发。
4. 正式 62,000 点注册表尚未物化，当前不得用于正式训练。
5. 质量阈值须先在 2,000 点试运行中验证，调整时必须升级策略版本。
6. 对外发布全国分布图须更换为符合公开地图要求的标准底图。

这些阻断项没有通过修改措辞隐藏，也没有把规划配置包装成已经可直接运行的
生产程序。

## 四、修订后结论

修订后的文档可以作为中国版 2020--2021 年季度嵌入的采样设计和工程开发依据。
它已经明确回答目标样本数、四层配额、空间抽样、补样、季度质量、弱语义、
数据划分、注册表和验收规则。

现阶段不能声称“62,000 个正式训练样本已经完成”。下一阶段应按正式方案第九节
开发季度采样适配器并重建候选清单，通过全部自动验收后再冻结生产注册表。

最终定稿再次提交空间统计、遥感数据和工程交付三个独立审查智能体复核。三个
审查均确认：不存在会阻止该采样方案文档交付的未披露 P0/P1 问题。
