# 浦江交流PPT第3、5、8页修订设计

## 目标

根据汇报反馈，重新解释P10C训练方法，并使用严格公平的稀疏Polygon协议比较
玄女、AEF与传统多源特征，替换当前第3、5、8页。

## 第3页：训练方法通俗化

页面保留“AEF思路到城市月度嵌入”的主线，但不再只罗列参数。

1. 月份困难重建：每个训练样本有65%概率启动月份遮挡；启动后从6个月中随机
   遮住1至4个月。`0.65`不是每个月的遮挡率。
2. 空间困难重建：每个样本有65%概率启动空间遮挡；启动后平均遮住约32%的
   空间块。
3. 模态困难重建：随机拿走S2、S1或Landsat中的部分数据源，要求模型利用剩余
   观测恢复完整信息。
4. OSM弱语义：使用建筑、主干路、次级路、铁路、水体、绿地、农业、居住、
   商业、工业、施工、步行路径、运动场13类粗粒度提示。
5. `semantic_probe_weight=0.14`是辅助损失系数，不是准确率、数据占比或类别数。
   13个临时线性探针只在训练期使用，交付时只保留64维通用嵌入。

## 第5页：三个圈选区域形成专题图

页面顶部只保留一句业务解释：

> 用户只需圈选3个目标区域，系统自动寻找可信背景，并在冻结嵌入底座的情况下
> 生成全域候选专题图。

主体按建筑、道路、水体三行组织，每行包含：

1. 原始影像上的3个用户圈选Polygon；
2. 玄女P10C + PU+Query预测；
3. AEF + 同一PU+Query预测；
4. 传统多源特征 + 同一PU+Query预测；
5. 独立测试GT。

PU表示只提供正类圈选，系统从未标注区域自动选择可靠背景；Query表示在目标
patch内使用高置信候选对原型进行轻微适配。水体结果若F1仍低，只表述为候选区域
发现，不宣称精确自动制图。

## 第8页：三特征源同协议比较

固定以下协议：

1. 任务：建筑、道路、水体；
2. 标注预算：每类3个训练折Polygon；
3. 支持Polygon：三个特征源共享相同位置；
4. 测试：固定fold-0的64个独立测试patch；
5. 下游方法：相同标准化、PU可靠背景、Query融合与阈值选择；
6. 玄女：P10C epoch800、2026年4月、64维；
7. AEF：2025年度官方嵌入、64维；
8. 传统特征：2026年4月S2、S1、Landsat、高分光学、高分SAR与光谱/局部统计，
   共42维；
9. 指标：Precision、Recall、F1、IoU、AUC、AP。

第8页以F1和AUC分组图为主，明确玄女是月度产品、AEF是年度产品。结论完全依据
新实验，不预设玄女必然领先。

4. 第3、5、8页分别由独立子智能体审查至PASS；
