# 全国十等分无缝中文交付设计

## 目标

重建全国 1280 m 父网格及其十等分交付包，使网格严格覆盖冻结的中国 ADM0 范围，
在海岸线、国界与 UTM 带界处不出现越界、正面积重叠或内部缝隙；所有面向用户的
目录、文件与说明使用中文。

## 已确认的问题

当前 V4 从 11 个独立 UTM 网格直接汇集而成。审计发现带界附近存在中国境内漏覆盖，
且部分边界网格延伸到中国范围外。因此 V4 只保留为历史审阅版本，不作为修正后的
最终交付。

## 空间网格规则

1. 中国范围固定为
   `geoBoundaries-CHN-ADM0-frozen-20260726`，交付几何统一为 WGS84（EPSG:4326）。
2. 保留 UTM 43N 至 53N 的 1280 m 格网锚点：UTM 坐标以 `(0, 0)` 为原点，
   列、行号分别由 `floor(easting / 1280)` 和 `floor(northing / 1280)` 定义。
   因此非边缘格仍与原有 AEF/UTM 网格对齐。
3. 每个 UTM 带的唯一归属面为“中国范围 ∩ 该 UTM 带的经度范围”。相邻归属面只共享
   边界线，不共享正面积，十一个归属面的并集等于中国范围。
4. 对每个归属面，在对应 UTM 坐标系生成所有与其相交的 1280 m 候选方格；每个候选格
   都与归属面相交裁切后才输出。内陆格仍为完整 1280 m × 1280 m；海岸、国界和 UTM
   带界格为合法的裁切多边形。
5. 因为相邻带都裁切到同一条经线，带界处不存在漏覆盖或正面积重叠。`parent_key`
   仍采用 `EPSG:grid_col:grid_row`，但边缘几何会因裁切而与历史 V4 不同。

## 十等分

修正后的全国 Shape 按空间连续性分成十个互不重叠的区域，尽量使每区 Shape 数相等；
编号继续遵从已确认的业务顺序：原 V3 第 8 区对应新第 1 区，随后为原第 1 至第 7 区，
第 9、10 区保持最后两个编号。由于边缘候选格集合改变，精确 Shape 数与当前 V4
可能不同，必须基于新集合重新计算并审计。

## 中文交付结构

新交付包独立版本目录为 `china_full_grid_tenfold_delivery_v5_20260824`。根目录使用：

```text
全国十个区域边界.shp / .shx / .dbf / .prj / .cpg
全国网格覆盖范围.shp / .shx / .dbf / .prj / .cpg
全国十个区域边界.gpkg
全国网格覆盖范围.gpkg
第01区/
  第01区边界.shp / .shx / .dbf / .prj / .cpg
  第01区边界.gpkg
  第01区_1280米网格.shp / .shx / .dbf / .prj / .cpg
  第01区_1280米网格.gpkg
...
第10区/
说明_请先阅读.md
质量检查.md
```

每个 Shape 的五个同名组成文件必须保留在同一目录。GeoPackage 是给只希望下载单个文件
的 QGIS 用户准备的等价副本。

## 质量门禁

1. 所有输出几何有效，CRS 为 EPSG:4326。
2. 所有格网都被中国范围包含，不存在正面积越界。
3. 中国范围减去全部格网并集的面积为零（允许不超过 1 平方米的浮点容差）。
4. 不同 UTM 带的格网之间没有正面积重叠；带界专项漏覆盖面积为零。
5. 十区 `parent_key` 唯一、互不重叠，合计等于全国修正后集合。
6. 中文 Shape/GPKG 均可独立由 GDAL/QGIS 读取；ZIP CRC 校验通过。

## 发布边界

本轮只生成本地 V5 交付包和代码/文档变更，不覆盖 V4，也不上传或修改 ModelScope。
