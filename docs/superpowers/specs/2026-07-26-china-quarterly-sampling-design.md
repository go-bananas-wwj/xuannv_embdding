# 中国版季度地理嵌入采样方案设计

## 1. 目标

参考《中国版 Alpha Earth 技术方案现有资源版》，为 2020 年和 2021 年季度
10 米全国地理嵌入训练冻结一套可复现、可审计、可直接落地的数据采样方案。

## 2. 样本规模

目标训练样本为 62,000 个 `1280 m x 1280 m` patch：

| 样本层 | 数量 |
| --- | ---: |
| 全国基础 1% 空间样本 | 57,405 |
| UTM 空间均衡补样 | 2,595 |
| 海岸线补样 | 500 |
| 城市、稀有地物、基础设施和困难区域补样 | 1,500 |
| 合计 | 62,000 |

主候选完成几何和季度质量验收后才冻结最终注册表。冻结前允许从同层、同区域的
有序候补池替换不合格候选；冻结后不再换点。所有层级执行跨 UTM 空间去重，并
保留采样原因和采样设计类型。全国统计只使用基础概率层；目标补样不伪造设计权重。

## 3. 空间抽样方法

全国陆地按 UTM 分区建立 1280 米规则网格，使用中心经度半开区间确定唯一 UTM
归属。相邻 `10 x 10` 个 patch 组成一个宏网格。完整宏网格用固定随机种子
`20260717` 和 SHA-256 哈希选择一个 patch；边界宏网格逐点枚举准确整数 `n`，
再以 `n / 100` 的概率接纳。跨 UTM footprint 重叠超过 1%时确定性去重，
并从基础层有序候补池补足到规划数量 57,405；注册表保留实际入选概率。

空间均衡补样按 UTM 分区有效面积平方根分配。海岸补样使用真实海洋面识别陆海
交界，不把河流、湖泊、省界或国界当作海岸。语义与困难区域补样使用土地覆盖、
OSM、DEM 和影像质量统计，不使用最终下游人工测试标签。

## 4. 时序与数据质量

每个空间 patch 同时服务于 2020Q1 至 2021Q4 八期产品。训练前按季度统计
Sentinel-2、Sentinel-1 和 Landsat 的有效观测。云、阴影、无效值和饱和像素
不计算重建损失；雪作为季节地表状态保留。空间样本与数据质量是两个独立阶段：
先冻结主候选及候补顺序，再进行质量审计；最终注册表冻结前才允许审计替换。

## 5. 数据划分

主模型自监督训练可以使用全部 62,000 个 patch。用于模型选择和论文报告的
固定验证集、测试集按空间块划分，不能随机打散相邻 patch，且不参与梯度更新。
目标比例为 90%/5%/5%，使用 EPSG:6933 的 50 km 父块和 25.6 km 跨集合
缓冲，同时保持省域、生态区和采样层级分布基本一致。

## 6. 交付物

1. 中文 Markdown 正式方案。
2. 中文 DOCX 正式方案。
3. 自包含的 62,000 点采样策略 JSON。
4. 样本注册表字段说明和验收规则。
5. 57,405 点基础抽样分布图，并明确其不是最终 62,000 点实采结果。

## 7. 验收原则

数量总和必须严格等于 62,000；patch ID、空间范围和几何哈希必须唯一；所有
样本位于中国研究边界内；补样与已有样本无重复；相同边界、网格版本、随机种子
和输入数据必须生成相同清单；最终清单发布前须通过空间分布、数据覆盖和人工抽查。
