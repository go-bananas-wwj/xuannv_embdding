# 中国版季度地理嵌入采样方案设计

## 1. 目标

参考《中国版 Alpha Earth 技术方案现有资源版》，为 2020 年和 2021 年季度
10 米全国地理嵌入训练冻结一套可复现、可审计、可直接落地的数据采样方案。

## 2. 样本规模

最终训练样本固定为 62,000 个 `1280 m x 1280 m` patch：

| 样本层 | 数量 |
| --- | ---: |
| 全国基础 1% 空间样本 | 57,405 |
| UTM 空间均衡补样 | 2,595 |
| 海岸线补样 | 500 |
| 城市、稀有地物、基础设施和困难区域补样 | 1,500 |
| 合计 | 62,000 |

补样只增加新样本，不替换基础样本。所有层级执行 patch 去重，并保留采样原因。

## 3. 空间抽样方法

全国陆地按 UTM 分区建立 1280 米规则网格。相邻 `10 x 10` 个 patch 组成一个
宏网格。完整宏网格用固定随机种子和 SHA-256 哈希选择一个 patch；边界宏网格
若只有 `n` 个有效 patch，则以 `n / 100` 的概率接纳该宏网格，保持每个有效
patch 的期望入选概率为 1%。

空间均衡补样按 UTM 分区有效面积平方根分配。海岸补样使用真实海洋面识别陆海
交界，不把河流、湖泊、省界或国界当作海岸。语义与困难区域补样使用土地覆盖、
OSM、DEM 和影像质量统计，不使用最终下游人工测试标签。

## 4. 时序与数据质量

每个空间 patch 同时服务于 2020Q1 至 2021Q4 八期产品。训练前按季度统计
Sentinel-2、Sentinel-1 和 Landsat 的有效观测，使用像素级云、阴影、雪和无效
值掩膜。空间样本与数据质量是两个独立阶段：先冻结候选空间清单，再进行数据
质量审计；质量不合格样本进入待补片清单，不静默替换。

## 5. 数据划分

主模型自监督训练可以使用全部 62,000 个 patch。用于模型选择和论文报告的
固定验证集、测试集按空间块划分，不能随机打散相邻 patch，且不参与梯度更新。
建议比例为 90%/5%/5%，同时保持省域、生态区和采样层级分布基本一致。

## 6. 交付物

1. 中文 Markdown 正式方案。
2. 中文 DOCX 正式方案。
3. 自包含的 62,000 点采样策略 JSON。
4. 样本注册表字段说明和验收规则。
5. 57,405 点基础抽样分布图，并明确其不是最终 62,000 点实采结果。

## 7. 验收原则

数量总和必须严格等于 62,000；patch ID、空间范围和几何哈希必须唯一；所有
样本位于中国研究边界内；补样与已有样本无重复；相同边界、网格版本、随机种子
和输入数据必须生成相同清单；最终清单发布前须通过空间分布、数据覆盖和人工抽查。
